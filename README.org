* Syllabus
** Course learning objectives-CLOs
#+ATTR_REVEAL: :frag (appear appear appear ...)
1. [ ] locate biomechanical state variables that appear in conservation principles
2. [ ] exemplify some basic biomechanical phenomenon that arise in living tissue
3. [ ] read the mechanical variables and expressions using the indicial notation 
4. [ ] perform vector algebraic operations on mechanical variables and expressions 
5. [ ] differentiate between the global and local forms of conservation principles
6. [ ] define the surface traction, stress and force concepts in a mechanical context
7. [ ] identify the role of divergence theorem between the global and local forms
8. [ ] read vector calculus operations appearing in the conservation principles
9. [ ] differentiate between the use of cartesian and curvilinear coordinates 
10. [ ] define concepts related to velocity and acceleration in the context of kinematics
11. [ ] solve for a mechanical variable using the conservation principles

* Code of Conduct & Ethics
#+ATTR_REVEAL: :frag (appear appear appear ...)
- The interpersonal communication in class is based on a level of minimum respect towards each other
- The class is a communal space, it is not a stage to show off (except for the instructor)
- Students are expected to arrive to class on a voluntary basis, involuntary participation is strongly discouraged
- Mechanics requires a direct teaching model where the role of the student is usually limited to a receiver, however, the students are encouraged to ask questions and participate in the learning process
