\section*{The Issue: Gradient and Divergence Index Conventions}
In continuum mechanics, there is a \textbf{persistent notational discrepancy} in how the gradient of a vector and the divergence of a tensor are written. This arises from:

1. The \textbf{natural mathematical definition} of the gradient operator.
2. The \textbf{comma notation} for partial derivatives, which can flip indices unintentionally.

\section*{Correct Definitions}
\subsection*{Gradient of a Vector}
The gradient of a vector \(\mathbf{v}\) should form a proper second-order tensor:
\[
\nabla \mathbf{v} = \frac{\partial v_j}{\partial x_i} \mathbf{e}_i \otimes \mathbf{e}_j = v_{j,i} \mathbf{e}_i \otimes \mathbf{e}_j,
\]
where:
\begin{itemize}
    \item \(i\) = \textbf{gradient index} (row index, associated with \(\nabla\)).
    \item \(j\) = \textbf{vector component index} (column index).
\end{itemize}

\subsection*{Divergence of a Tensor}
The divergence contracts the \textbf{gradient index} (first index):
\[
\nabla \cdot \mathbf{S} = \frac{\partial S_{ji}}{\partial x_j} \mathbf{e}_i = S_{ji,j} \mathbf{e}_i.
\]

\section*{Common Mistake}
Many texts incorrectly write:
\[
\nabla \mathbf{v} = v_{i,j} \mathbf{e}_i \otimes \mathbf{e}_j \quad \text{(transposed!)}
\]
This leads to the \textbf{wrong divergence}:
\[
\nabla \cdot \mathbf{S} = S_{ij,j} \mathbf{e}_i \quad \text{(only valid if \(\mathbf{S}\) is symmetric)}.
\]

\section*{Why This Matters}
\begin{itemize}
    \item If \(\mathbf{S}\) is \textbf{non-symmetric} (e.g., in polar materials), \(S_{ij,j}\) is \textbf{incorrect}.
    \item The comma notation \(v_{i,j}\) \textbf{hides the transposition} inherent in \(\nabla \mathbf{v}\).
\end{itemize}

\section*{Recommended References}
\begin{itemize}
    \item \textbf{Gurtin et al. (2010)}: Uses \(v_{j,i}\) and \(S_{ji,j}\) consistently.
    \item \textbf{Truesdell \& Noll (2004)}: Explicitly warns about index ordering.
    \item \textbf{Holzapfel (2000)}: Correctly uses \(\sigma_{ji,j}\) for divergence.
\end{itemize}

\section*{Key Takeaway}
Always:
\[
\nabla \mathbf{v} = v_{j,i} \mathbf{e}_i \otimes \mathbf{e}_j, \quad \nabla \cdot \mathbf{S} = S_{ji,j} \mathbf{e}_i.
\]
Verify if authors assume symmetry (\(S_{ij} = S_{ji}\)) before using \(S_{ij,j}\).
